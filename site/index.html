Photographs of cards, to a standard.

Point a camera at a card and you get a snapshot. This gives you the card: flat on, square, cropped to its true size, with the corners close enough to judge — the same way, every time.

Install it Source on GitHub

What it does

Rectified, not cropped

Every card is dewarped to a true 88×63 mm and squared, so a hundred cards come out looking like a hundred cards from one seller.

Corner close-ups

Four crops per card, cut as you scan. Corner whitening and edge wear decide the grade, and a whole-card photograph resolves neither.

Extra shots

A second pass for the few cards that need one — a holo tilted so the foil reads, a crease close up. Never rectified; the angle is the point.

Batches that export

Scan a pile, check it, download one folder, archive, next. Filenames carry their order so the gallery image lands first.

Counts a bulk uploader can use

Uploaders chunk a flat folder by photos-per-card. It tells you that number before you download, and splits the folder when a batch has two.

Yours, on your hardware

Runs on a Raspberry Pi or any machine with Docker. No account, no upload, no third party between you and your collection.

Install

Docker, and two minutes.

mkdir tcg-scanner && cd tcg-scanner
curl -O https://raw.githubusercontent.com/samrpat/tcg-scanner/main/docker-compose.release.yml
printf 'POSTGRES_PASSWORD=%s\n' "$(openssl rand -base64 24)" > .env
docker compose -f docker-compose.release.yml up -d

Then open http://localhost:8080 and choose a password. The database sets itself up on first boot and a short introduction explains the rest. Nothing else to run.

Scanning from a phone needs the https:// address, because a browser will not hand a page the camera over plain HTTP. The app tells you which address to use.

Honest about what it is not

  • One account per install. There is no way to add a second person.
  • It has not been run on a Raspberry Pi yet. That is the target and the instructions are right, but every measurement so far is from a Mac.
  • Self-signed TLS only. Fine on a home network; there is no Let's Encrypt.
  • No import. An existing collection cannot be brought in.
  • English cards. The card-back reference is the English back.
