# Snapshot: the full app, 8 September 2026

This is a frozen copy of the whole source tree taken immediately before the split into a
lean scanner build. It is here because this project is not under version control, so
without a copy there would be nothing to go back to.

It is a **reference copy, not a second installation.** Nothing runs from this directory,
and it deliberately has no database or images of its own — running it would give you an
empty second collection, not the one you have.

## If you want the full app back

You do not need this directory for that. Everything it contains is still live in the
working tree, and full mode is one command:

    make full

That is the app exactly as it was: identification, conditioning, pricing, eBay titles and
item specifics, sold-price lookups, upload files, and the public photo host. Same database,
same photographs, same batches.

## What this is actually for

Reading, and repair. If a scanner-mode change ever breaks something that used to work, the
version that worked is here, file for file, and can be diffed against the live tree:

    diff -ru archive/full-2026-09-08/api/app api/app

## What is not in it

`data/` — the database dump, the card photographs, the art cache. Those are the real
collection; they were never copied and were never touched by the split. `node_modules` and
build output are also excluded, since both are regenerated by a build.
